Câu Hỏi Thường Gặp

Hệ thống hỗ trợ những định dạng xuất file nào?

Hiện tại hệ thống hỗ trợ xuất báo cáo dưới dạng Excel (file chuẩn CSV), JSON cho lập trình viên và định dạng bản in trực tiếp.

Mã Composite Code được sử dụng để làm gì?

Mã Composite Code đóng vai trò như một mã định danh duy nhất cho lô hàng, giúp lưu trữ, quản lý và truy xuất lịch sử kiểm nghiệm nhanh chóng.

Dữ liệu phân tích có lưu trên máy chủ không?

Công cụ hoạt động trực tiếp trên trình duyệt của bạn (Client-side), đảm bảo tính bảo mật và tốc độ xử lý tức thì.
